5·6학년 두 명이 한 팀이 되어, 학교생활의 불편을 푸는 앱을 Canva Code로 만들어요. 친구가 써 보고 맞게 나오면 완성!

1주차

  1. 팀 이름 정하기

    팀 이름은 갤러리(공개 웹사이트)에 올라가요. 실제 이름이나 별명은 넣지 않아요.

  2. 문제 찾기

    팀 학습지를 따라 해요.

    • 각자 학교 하루에서 불편했던 장면을 포스트잇 2장에 써요. ("언제 + 무엇이 불편")
    • 서로 읽고 이야기한 뒤, 후보 3개를 기준표로 점수 매겨 1개를 골라요.
    • 앱 설계도(PRD)를 쓰고, 꼭 필요한 기능 3개와 시험 문장을 정해요.

    시험 문장 예: 친구가 ① 24를 입력하고 ② [뽑기]를 세 번 누르면 ③ 서로 다른 번호 3개가 나오면 완성!

  3. 기획서 앱에 옮겨 쓰기

    선생님 확인을 받은 설계도를 기획서 앱에 옮겨 써요. 3단계에서 요청문이 완성돼요.

    기획서 앱 열기

  4. 요청문 복사하기

    기획서 앱 안의 [복사] 버튼은 아이패드에서 작동하지 않을 수 있어요. 이렇게 복사해요.

    1. 3단계 큰 글상자 안을 길게 눌러요.
    2. 나온 메뉴에서 [전체 선택]을 눌러요.
    3. 다시 길게 눌러 [복사]를 눌러요.

    그래도 안 되면 선생님께 말해요. 빈칸 기획서(Canva 문서)로 바꿔 쓸 수 있어요.

  5. Canva Code로 만들기

    • 팀 Canva 디자인에서 Canva Code를 열고 요청문을 붙여 넣어요.
    • AI가 보여 주는 화면 목록과 기능 설명을 읽고, 궁금한 점 3가지에 답해요.
    • 첫 화면 → 기능 1 → 기능 2 → 기능 3 순서로, 한 번에 한 가지씩 만들어요.
    • 끝나기 전에 잘 되는 상태를 저장하고, 디자인 이름을 '팀이름_앱이름'으로 바꿔요.
    • 주간 과제 카드에 다음 주까지 할 일을 적어요.

요청 카드: AI에게 잘 부탁하는 법

잘 통하는 요청 4가지

  1. 하나씩: 한 번에 한 가지만 부탁해요.
  2. 보이는 대로: 화면에 보이는 그대로 말해요. ("버튼을 눌러도 아무 일도 안 일어나.")
  3. 지키기: "다른 건 그대로 두고"를 붙여요.
  4. 저장: 잘 되면 바로 저장하고, 고치기 전에 복제해 둬요.

바로 쓰는 고치기 요청

  • "버튼을 누르면 아무 일도 안 일어나. 버튼을 누르면 ___이 보이게 고쳐 줘."
  • "글자가 너무 작아. 제목 글자를 두 배로 키워 줘."
  • "다른 건 그대로 두고, ___만 바꿔 줘."
  • "아이패드에서 화면이 잘려. 화면 안에 다 보이게 고쳐 줘."
  • "방금 고친 뒤로 ___이 안 돼. 고치기 전처럼 ___이 되게 해 줘."
  • "디자인만 바꿔 줘. 기능은 그대로 두고, 가장 중요한 버튼이 먼저 보이게 해 줘."

만들기 체크리스트

만들기

다듬기 (화면 점검 5가지)

1주차와 2주차 사이: 이어서 고치기 (선택)

  • 팀 디자인은 짝과 공유되어 있어서, 둘 중 누구나 이어서 고칠 수 있어요.
  • 고치기 전에 디자인을 복제해 '팀이름_앱이름_백업'으로 남겨 둬요. AI가 앱을 망가뜨려도 되돌릴 수 있어요.
  • 주간 과제 카드에 적은 할 일부터 해요.
  • 집에서 할 때도 실제 이름·사진 같은 개인정보는 넣지 않아요.

2주차

  1. 마무리하고 게시 전 안전 점검

    남은 기능이나 오류를 고친 뒤, 게시하기 전에 모두 확인해요.

    게시 전 안전 점검

  2. 웹사이트로 게시하기

    Canva에서 [웹사이트로 게시]를 해요. 게시한 주소(https://로 시작)는 제출할 때 써요.

  3. 서로 써 보기

    다른 팀 앱을 먼저 설명 없이 써 본 뒤, 카드의 시험 문장대로 해 봐요. 써 보기 카드에 결과와 한 줄 피드백을 남겨요. "이 앱이 더 유용해지려면 ___."

  4. 제출하기

    Google Forms로 팀 이름, 앱 이름, 한 줄 소개, 불편, 기능 3개, 시험 문장, 게시 링크를 내요. 제출 전에 링크가 열리는지 한 번 확인해요.

    제출 양식 링크는 2주차에 선생님이 알려 줄게요.

  5. 발표하기

    발표자료 4장을 채우고, 팀당 5분 발표해요(게시 링크로 시연 2분 포함). 시연이 실패해도 괜찮아요.

    1. 우리 팀과 앱 이름
    2. 어떤 불편을 해결했나요?
    3. 우리 앱을 소개합니다 (시험 문장 순서대로 시연)
    4. 만들면서 알게 된 것

우리 동아리 작품

2주차 뒤에 모든 팀의 앱이 갤러리에 올라가요. Canva 게시가 닫혀도 갤러리에서 계속 실행할 수 있어요.
